# QA Engineer — Portfolio

QA Engineer с опытом 3+ лет.

В этом репозитории собраны примеры моей работы с тестированием веб-приложений, API, базами данных и автоматизацией.

## Что здесь

* **Тестирование** — чек-листы, тест-кейсы, баг-репорты и анализ требований.
* **API** — REST API, JSON, HTTP, позитивные и негативные сценарии.
* **SQL** — проверки данных и связей между сущностями.
* **Automation** — Java, JUnit 5, Rest Assured, Maven.

## Подход

При тестировании обращаю внимание не только на happy path, но и на негативные сценарии, граничные значения, бизнес-логику, целостность данных и права доступа.

## Стек

`Java` · `SQL` · `REST API` · `Postman` · `JUnit 5` · `Rest Assured` · `Git` · `Maven`
