# QA Portfolio

Портфолио с примерами моей работы в области тестирования программного обеспечения.

## Что здесь представлено

### Анализ требований
Анализ требований продукта, выявление неоднозначностей, рисков и вопросов к бизнес-логике.

`product-analysis/`

### Стратегия тестирования
Пример формирования стратегии: области тестирования, приоритеты, виды тестирования, регрессионный подход и автоматизация.

`test-strategy/`

### Чек-листы
Функциональный чек-лист для основных пользовательских сценариев веб-приложения.

`checklists/`

### Тест-кейсы
Примеры подробных тест-кейсов с предусловиями, тестовыми данными, шагами и ожидаемым результатом.

`test-cases/`

### Баг-репорты
Примеры оформления найденных дефектов с Severity, Priority, шагами воспроизведения, ожидаемым и фактическим результатом.

`bug-reports/`

### API Testing
Примеры проверок REST API: HTTP-коды, JSON, авторизация, позитивные и негативные сценарии.

`api-testing/`

### Database Testing
Примеры SQL-запросов для проверки данных, связей между сущностями и согласованности API и базы данных.

`sql/`

### Automation
Небольшой демонстрационный проект автоматизации API-тестов на Java, JUnit 5 и Rest Assured.

`automation/`

## Используемые технологии

- Java
- JUnit 5
- Rest Assured
- REST API
- HTTP
- JSON
- SQL
- Git / GitHub
- Maven

## Подход к тестированию

В работе стараюсь смотреть на продукт не только с точки зрения проверки отдельных функций, но и через пользовательские сценарии, бизнес-риски и возможные последствия ошибок.

Основное внимание уделяю:

- позитивным и негативным сценариям;
- граничным значениям;
- бизнес-логике;
- API и данным;
- авторизации и правам доступа;
- регрессионному тестированию;
- качеству и однозначности требований;
- автоматизации повторяющихся проверок.

## Статус проекта

Проект развивается и дополняется новыми примерами тестирования и автоматизации.
