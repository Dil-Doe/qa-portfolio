# Test-cases

## TC-001 — Успешная авторизация

**Приоритет:** Высокий

**Предусловия:**

* Зарегистрирован пользователь.
* Страница авторизации доступна.

**Тестовые данные:**

* Корректный email.
* Корректный пароль.

**Шаги:**

1. Открыть страницу авторизации.
2. Ввести корректный email.
3. Ввести корректный пароль.
4. Нажать кнопку «Войти».

**Ожидаемый результат:**

Пользователь успешно авторизован и перенаправлен в раздел, доступный авторизованным пользователям.

## TC-002 — Авторизация с неверным паролем

**Приоритет:** Высокий

**Предусловия:**

* Зарегистрирован пользователь.

**Тестовые данные:**

* Корректный email.
* Некорректный пароль.

**Шаги:**

1. Открыть страницу авторизации.
2. Ввести корректный email.
3. Ввести неверный пароль.
4. Нажать кнопку «Войти».

**Ожидаемый результат:**

Авторизация не выполняется. Пользователь остаётся неавторизованным и получает сообщение об ошибке.

## TC-003 — Доступ к защищённому ресурсу без авторизации

**Приоритет:** Критический

**Предусловия:**

Пользователь не авторизован.

**Шаги:**

1. Открыть защищённую страницу напрямую.
2. Проверить результат.

**Ожидаемый результат:**

Доступ к странице запрещён. Пользователь перенаправляется на страницу авторизации либо получает соответствующий ответ от API.

## TC-004 — Добавление товара в корзину

**Приоритет:** Высокий

**Предусловия:**

* Пользователь авторизован.
* Товар доступен для покупки.

**Шаги:**

1. Открыть каталог товаров.
2. Открыть карточку товара.
3. Нажать «Добавить в корзину».

## TC-005 — Изменение количества товара

**Приоритет:** Высокий

**Предусловия:**

Товар добавлен в корзину.

**Тестовые данные:**

* Начальное количество: 1.
* Новое количество: 2.

**Шаги:**

1. Открыть корзину.
2. Изменить количество товара с 1 на 2.
3. Проверить количество товара.
4. Проверить итоговую стоимость.

**Ожидаемый результат:**

Количество товара изменилось на 2. Итоговая стоимость пересчитана корректно.

## TC-007 — Создание заказа

**Приоритет:** Критический

**Предусловия:**

* Пользователь авторизован.
* В корзине находится хотя бы один доступный товар.
* Заполнены необходимые данные для оформления заказа.

**Шаги:**

1. Открыть корзину.
2. Перейти к оформлению заказа.
3. Заполнить обязательные поля.
4. Подтвердить заказ.

**Ожидаемый результат:**

Заказ успешно создан. Пользователю отображается информация о созданном заказе.

**Предусловия:**

## TC-009 — Запрет доступа к заказу другого пользователя

**Приоритет:** Критический

**Предусловия:**

* Пользователь A авторизован.
* Существует заказ, принадлежащий пользователю B.

**Шаги:**

1. Авторизоваться под пользователем A.
2. Получить идентификатор заказа пользователя B.
3. Попытаться открыть заказ пользователя B.
4. Проверить ответ системы.

**Ожидаемый результат:**

Доступ к заказу пользователя B запрещён. Информация о чужом заказе не раскрывается.

---

## TC-010 — Проверка данных созданного заказа

**Приоритет:** Критический

**Предусловия:**

* Пользователь авторизован.
* В корзине находятся товары.

**Шаги:**

1. Создать заказ.
2. Сохранить идентификатор заказа.
3. Открыть созданный заказ.
4. Сравнить товары, количество и итоговую стоимость заказа с содержимым корзины.

**Ожидаемый результат:**

Созданный заказ содержит те же товары, количество и итоговую стоимость, которые были в корзине на момент оформления заказа.
